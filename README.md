# RTOS

Embedded RTOS examples built from scratch with the STM32 HAL library.

## What is included

This repository collects small, focused programs for learning and experimenting
with real-time firmware concepts on STM32 microcontrollers.

## Getting started

1. Open the example you want to run in STM32CubeIDE.
2. Select the matching STM32 target and configure the required peripherals.
3. Build the project and flash it to the development board.

Hardware-specific settings belong in the corresponding example project. Check
the source and CubeMX configuration before flashing an example to a different
board.
